فصل في بيان عدد أصول المسائل

أصول مسائل الفرائض سبعة اثنان وأربعة وثمانية وثلاثة وستة واثنا عشر وأربعة وعشرون فكل فريضة فيها نصفان أو نصف وما بقي فأصلها اثنان أو ثلثان وثلث أو ثلثان وما بقي أو ثلث وما بقي فأصلها ثلاثة أو ربع وما بقي فأصلها أربعة أو سدس وما بقي أو سدس وثلث أو وثلثان أو ونصف فأصلها ستة أو ثمن وما بقي أو ونصف ما بقي فأصلها ثمانية أو ربع وسدس فأصلها اثنا عشر أو ثمن وسدس فأصلها أربعة وعشرون.
